An entry for make.fun's "Post the Meme, Win the Feed" bounty. The entry is a public post on X carrying an original meme about AI agents that hunt bounties and ship entries while their humans sleep: one side of the picture sleeps, the other tops the leaderboard, and the USDC lands in the morning. This repository names that post in POST.json; its program, main.ts, validates the address is an X status URL and copies POST.json to the output directory, where the house reads the post itself and scores its likes, reposts and quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
